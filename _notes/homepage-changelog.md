# Change Log
- **2024-11-24:** - This website is **built upon [Indie Web principles](https://indieweb.org/principles).
    - I continue to use [Notion](http://notion.so) with [Super](https://super.so) to reduce technical friction in updating my website, and to make myself overcome perfectionism by publishing quickly.
        - To serve you better, I modeled after [jamesclear.com](http://jamesclear.com) because he communicates benefits of his website and services superbly.
        - I also modeled this site after Nate Kadlac’s because of his supreme [design](https://www.notion.so/Nate-Kadlac-8539a0d8f27543acb416cc6b8c49d1bf?pvs=21) tastes and skills. I took his design course too, which I highly recommend!
        - My website continues to be a “public” Personal Knowledge Management (PKM) system.
            - I use Apple Notes for quick jot-downs like grocery lists and notes to self.
            - I use [Google Docs](https://docs.google.com) for drafts inviting collaboration.
            - I wish Notion is faster and supports offline sync. ☹️
- **2024-04-14:** Wow, it’s been almost exactly a year! I made a detour to try using [framer.ai](http://framer.ai) to build this site. It ended up being quite a frustrating process because of the hassle of a CMS port and not-great defaults for non-designers. Luckily [super.so](http://super.so) has improved, with the ability to make nested nav bars and custom fonts, so I switched back.

- **2022-09-20:** Has it been this long?! Rehauled website modeling after [jamesclear.com](http://jamesclear.com). Archived the old website layout below so I can appreciate how far I’ve come.
