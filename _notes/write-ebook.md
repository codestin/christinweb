## Pre-sale on Gumroad

- Write *copy* not *content*, copy successful gumroad products of a similar category
[https://dvassallo.gumroad.com/l/twitter-audience](https://dvassallo.gumroad.com/l/twitter-audience)
- Generate a placeholder PDF with a deadline as a product to be sold
- Set price as %X or pay as you want
- Post on kind, small communities

## Writing

- Brain dump everything onto 1 Google Doc
    - Pretend like you are writing to 1 ideal reader
    - Google Doc is also great b/c there's offline access, easy commenting system, version control

## Formatting

- Follow Daniel Vassallo's advice
- Use Page Sizer Add-On to make the page 6" x 9"
[https://workspace.google.com/marketplace/app/page_sizer/595382898724](https://workspace.google.com/marketplace/app/page_sizer/595382898724)

- [Blurb.com](http://blurb.com/) uses 6" x 9" for printed copies too
[https://www.blurb.com/getting-started#/novel/sell](https://www.blurb.com/getting-started#/novel/sell)

## Structuring

- Create Table of Contents with sections, move brain dumps to each section
    - Refer to a published book you admire to see what sections you need
- If the ideas require a certain logical order, group similar ideas, place each idea onto a post-it note (or use Miro) and arrange them
- Remove any points that do not add to the content, save the points into a separate Google Doc just in case
- Use Acknowledge, Compare, Reframe Framework for the introduction
- At this point, seek feedback from friends to see if the structure makes sense

## Write Some More

- Start cranking out words, working one section at a time
- Add a visual analogy to each point if possible
- Periodically check if I am following Simone Silverstein's [One-Pager](https://docs.google.com/document/d/1JgUYPb_PpcUCvVCAccA0v01mWfE-B4cwU5K9mV0nfY0/edit) writing guide
